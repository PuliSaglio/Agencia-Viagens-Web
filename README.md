# 🌍 Agência de Viagens Fictícia

Este projeto consiste em um site estático de uma agência de viagens fictícia, desenvolvido utilizando apenas **HTML5 e CSS3**, com foco em **estrutura semântica, estilo, responsividade** e **boas práticas de organização de componentes**.

## 📌 Objetivo

Desenvolver uma aplicação web com propósito claro: apresentar pacotes turísticos, destinos disponíveis, informações institucionais e canais de contato.
---

## 🗂️ Estrutura de Páginas

A aplicação será composta por **cinco páginas principais**, todas com objetivo claro:

| Página         | Descrição                                                                 |
|----------------|---------------------------------------------------------------------------|
| `index.html`   | Página inicial com destaques de destinos, promoções e menu de navegação. |
| `destinos.html`| Lista de destinos com imagens, descrições e tabela de preços.             |
| `pacotes.html` | Apresenta pacotes promocionais e personalizados para diferentes perfis.   |
| `sobre.html`   | Informações sobre a agência, missão, visão e equipe.                      |
| `contato.html` | Formulários de contato, orçamento e inscrição em newsletter.              |
